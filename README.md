#  Mon Portfolio - Muhozalevy

Bienvenue sur le dépôt de mon portfolio personnel. Ce site regroupe l'ensemble de mes réalisations en tant que développeur React, mettant en avant mes compétences en gestion d'état, immuabilité et intégration d'APIs.



## Stack Technique

* **Framework :** [React](https://reactjs.org/) (Vite)
* **Style :** CSS3 / Modules CSS 
* **Déploiement :** GitHub Actions & GitHub Pages
* **Icônes :** Lucide-React / FontAwesome

## Projets Présentés

### 1. Gestionnaire de Contacts
* **Description :** Application CRUD complète avec gestion fine de l'immuabilité pour les modifications de tableaux.

### 2. Currency Converter
* **Description :** Utilisation de `useEffect` et de l'API ExchangeRate pour des conversions en temps réel.

### 3. Todo List Pro
* **Description :** Ma toute première application déployée avec succès, gérant le filtrage et le LocalStorage.

## ⚙️ Installation Locale

1.  **Cloner le projet :**
    ```bash
    git clone [https://github.com/Muhozalevy/portfolio.git](https://github.com/Muhozalevy/portfolio.git)
    ```
2.  **Installer les dépendances :**
    ```bash
    npm install
    ```
3.  **Lancer en mode développement :**
    ```bash
    npm run dev
    ```
